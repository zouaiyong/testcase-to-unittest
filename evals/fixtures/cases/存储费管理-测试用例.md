# 存储费管理-测试用例

> 来源：存储费管理 PRD v1.3。本文件为定稿用例，编号稳定；判据以本文件为准。

## 范围声明

- 测：月存储费计算口径、费用按权重分摊、账单提交校验、账单审核。
- 不测：账单列表的分页与排序（沿用公共组件）。
- 需求缺口：逾期滞纳金的日利率尚未由财务确认，相关判据标【待确认】。

## 存储费计算

### 月存储费口径

#### TC-0001 按体积×单价×在库天数÷当月天数计算月存储费，保留两位小数四舍五入 【P0】

- 前置条件
  - 仓库 WH01 已配置存储单价
- 操作步骤
  - 分别用两组数据计算月存储费
- 预期结果
  - 体积 12.345 m³、单价 3.2 元/m³/月、在库 17 天、当月 31 天：月存储费 = 21.66 元
  - 体积 8.23 m³、单价 3.00 元/m³/月、在库 15 天、当月 30 天：月存储费 = 12.35 元
  - 结果固定保留两位小数，第三位四舍五入（12.345 → 12.35，不得截断为 12.34）

#### TC-0002 费用按权重分摊到各货主，尾差并入最后一项，合计恒等于总额 【P0】

- 前置条件
  - 一笔总额需要按权重拆到多个货主
- 操作步骤
  - 分别用两组数据分摊
- 预期结果
  - 总额 100.00、权重 1:1:1：分摊结果为 33.33、33.33、33.34
  - 总额 57.89、权重 2:3:5：分摊结果为 11.58、17.37、28.94
  - 每组分摊结果的合计都等于总额，不多一分不少一分
  - 每一项都保留两位小数

### 账单提交

#### TC-0003 仓库编码或账期为空时拦截提交 【P0】

- 前置条件
  - 其余参数合法
- 操作步骤
  - 分别用空仓库编码、空账期提交
- 预期结果
  - 仓库编码为空：提交被拦截，提示「仓库编码不能为空」
  - 账期为空：提交被拦截，提示「账期不能为空」
  - 拦截时不生成账单

#### TC-0004 同一仓库同一账期已存在账单时拦截重复提交 【P0】

- 前置条件
  - 仓库 WH01 在账期 2026-09 已有账单
- 操作步骤
  - 再次以 WH01 + 2026-09 提交
- 预期结果
  - 提交被拦截，提示「该仓库本账期已存在账单，不可重复提交」
  - 不生成新账单

#### TC-0005 仓库已停用时拦截提交 【P1】

- 前置条件
  - 仓库 WH09 在主数据里状态为停用
- 操作步骤
  - 以 WH09 提交账单
- 预期结果
  - 提交被拦截，提示「仓库已停用，不可提交账单」
  - 不生成账单
  - 不去查询该仓库是否已有账单（停用校验先于重复校验）

#### TC-0006 参数合法时生成待审核账单 【P0】

- 前置条件
  - 仓库 WH01 正常，账期 2026-09 无账单
- 操作步骤
  - 以体积 12.345 m³、单价 3.2 元/m³/月、在库 17 天、当月 31 天提交
- 预期结果
  - 生成一条账单，状态为「待审核」
  - 账单金额 = 21.66 元（口径同 TC-0001）
  - 账单的仓库编码与账期与提交参数一致
  - 页面跳转到账单详情并提示「提交成功」

### 账单审核

#### TC-0007 只有待审核账单可审核，审核后状态为已审核 【P0】

- 前置条件
  - 存在一条待审核账单与一条已审核账单
- 操作步骤
  - 分别审核两条账单
- 预期结果
  - 待审核账单审核后状态变为「已审核」
  - 已审核账单再次审核被拦截，提示「只有待审核账单可审核」
  - 账单不存在时提示「账单不存在」

## 账单列表与导出

#### TC-0008 列表页金额展示 【P2】

- 前置条件
  - 列表中有金额超过千位的账单
- 操作步骤
  - 打开账单列表
- 预期结果
  - 金额列按千分位展示，右对齐
  - 待审核账单的状态以橙色标签展示

#### TC-0009 导出账单 Excel 【P1】

- 前置条件
  - 列表中有账单
- 操作步骤
  - 点击「导出」
- 预期结果
  - 生成 Excel 文件，列顺序与列表页一致
  - 导出文件进入下载中心

## 逾期滞纳金

#### TC-0010 逾期账单按日利率计收滞纳金【待确认】 【P1】

- 前置条件
  - 存在已逾期的账单
- 操作步骤
  - 计算滞纳金
- 预期结果
  - 滞纳金 = 账单金额 × 日利率 × 逾期天数，日利率以财务口径为准【待确认】
  - 结果保留两位小数【待确认】
